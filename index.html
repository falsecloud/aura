Aura APT repository

Signed Debian packages for Aura. The repository metadata is served as GitHub Release assets, so the large package stays on the release page.

install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://github.com/falsecloud/aura/releases/latest/download/aura-archive-keyring.gpg \
  | tee /etc/apt/keyrings/aura.gpg >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/aura.gpg] https://github.com/falsecloud/aura/releases/latest/download/ ./" \
  | tee /etc/apt/sources.list.d/aura.list
apt update
apt install aura-weather

Run the commands above with root privileges. This is a signed third-party repository, not Debian's official archive.
